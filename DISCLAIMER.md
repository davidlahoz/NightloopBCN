## Platform Constraints

**This demo will only run on:**
- Chrome (or Chromium-based browsers)
- Windows
- WebGPU-capable hardware (RTX 40-series or newer, AMD RDNA 2+, or equivalent)
- 2560x1440 or higher (designed for 1440p @ 90 FPS)

**There is no fallback.** No WebGL path. No mobile support. No feature detection branches. If your browser doesn't support WebGPU, you will see a single line of text. That is intentional.
